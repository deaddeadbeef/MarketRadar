# This repo is skill-triggered MarketRadar

When working here as a product (not a one-off code patch), load the `radar` skill (`/radar hunt|brief|ready|bars`). Daily automation uses param `hunt`.

Grok mines X and public sources, writes the briefing file, and analyzes join/tape. The desktop World Events page is only how the human **receives** that briefing. Press **R** after a hunt.

Do not treat this checkout as a generic trading workbench. Pending binaries across domains. Research only.

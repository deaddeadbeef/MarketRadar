# This repo is skill-triggered MarketRadar

When working here as a product (not a one-off code patch), load the `market-radar` skill (`/market-radar hunt|brief|ready|bars|open`). Daily automation uses param `hunt`. Repo skill lives in `.grok/skills/market-radar/`; install into Grok with `scripts/install-market-radar-skill.ps1`.

Grok mines X and public sources, writes the briefing file, analyzes join/tape, and opens World Events. Press **R** if the desktop is already running.

Do not treat this checkout as a generic trading workbench. Pending binaries across domains. Research only.

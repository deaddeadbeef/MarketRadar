# This repo is skill-triggered MarketRadar (headless CLI)

When working here as a product (not a one-off code patch), load the `market-radar` skill (`/market-radar hunt|brief|ready|bars`). Daily automation uses param `hunt`.

Grok mines X and public sources, writes the briefing file, and analyzes join/tape. The human **receives** that briefing from the CLI (`catalyst-radar brief` JSON). Ops may file JSON into Notion outside this repo. Do not press R. Do not open the desktop or TUI.

Do not treat this checkout as a generic trading workbench. Pending binaries across domains. Research only. Never fake a buy call.
